# UI 界面与交互设计规范 (UI Specification)

本规范完全参考 `ui_example` 的界面结构、样式风格与交互流程，结合中国象棋特有的对局需求进行定制（除棋盘使用中国象棋专用渲染外，其余所有 UI 组件及侧边栏保持一致）。

---

## 1. 页面整体布局架构

整个页面采用居中单页布局，分为顶部标题比分栏、中间主对局区、弹窗浮层及底部技术说明区块：

```text
+-----------------------------------------------------------------------+
|                       #content-title (标题与比分)                       |
|   [黑方比分徽章]           中 国 象 棋 (主标题)          [红方比分徽章]   |
+-----------------------------------------------------------------------+
|                       #game-layout (主对局区)                         |
|  +-----------------------------------+ +---------------------------+  |
|  | #border-frame (棋盘及外框)        | | #ai-panel (侧边栏)        |  |
|  |  +-----------------------------+  | |  AI 搜索评分              |  |
|  |  | #board-options (多级菜单)   |  | |  深度 / 节点 / NPS / 评估 |  |
|  |  |  [开始 / 说明 / 模式 / 先手] |  | |  实时对局统计表格         |  |
|  |  +-----------------------------+  | |  实时状态指示器           |  |
|  |  | #board-container (象棋棋盘) |  | |                           |  |
|  |  +-----------------------------+  | +---------------------------+  |
|  +-----------------------------------+                                |
+-----------------------------------------------------------------------+
|                      #game-summary (对局总结浮层)                      |
|                   [胜负提示文本]   [再来一局按钮]                       |
+-----------------------------------------------------------------------+
|                      #engine-note (底部说明区块)                       |
|             象眼 C++/WASM 引擎原理 / 算力提示 / 文档与源码链接         |
+-----------------------------------------------------------------------+
```

---

## 2. 核心 UI 组件与交互细则

### 2.1 顶部标题与比分栏 (`#content-title`)
* **圆形计分徽章 (`.title-counter`)**：
  * 左侧 `#black-counter`：深色半透明圆环，显示黑方计分/胜局数。
  * 右侧 `#red-counter`：红/浅色半透明圆环，显示红方计分/胜局数。
* **主标题 (`#title`)**：
  * 居中展示艺术标题“中 国 象 棋”，每个字交替颜色与立体阴影样式。

### 2.2 棋盘外框与多级菜单遮罩 (`#board-options`)
在对局未开始或暂停时，遮罩层浮于棋盘上方：
1. **主菜单 (`#menu`)**：
   * 【开始】按钮 (`#startbtn`)：触发模式选择菜单。
   * 【说明】按钮 (`#helpbtn`)：弹出玩法与规则提示。
2. **模式选择菜单 (`#menu-mode`)**：
   * 【本机双人】按钮 (`#pvpbtn`)
   * 【人机对战】按钮 (`#pvebtn`)
   * 【机机对战】按钮 (`#evebtn`)
   * 【返回】按钮 (`.returnbtn`)：带 SVG 箭头图标，返回上一级。
3. **先手选择菜单 (`#menu-mode-pve`)**：
   * 【玩家先走（执红）】按钮 (`#pfbtn`)
   * 【电脑先走（执黑）】按钮 (`#efbtn`)
   * 【返回】按钮 (`.returnbtn`)：返回模式选择菜单。

### 2.3 侧边 AI 搜索评分面板 (`<aside id="ai-panel">`)
* **外观风格**：深色现代科技卡片（背景 `#20242b`，半透明微光边框 `rgba(255,255,255,0.08)`，浮雕阴影）。
* **标题区**：
  * 主标题：“AI 搜索评分”
  * 副标题：“记录每一步的搜索深度、节点数、耗时、NPS 和 UCCI 评估分数。”
* **搜索数据表格 (`#ai-stats-table`)**：
  * 列定义：
    1. `#`：手数序号
    2. `方`：行棋方（红/黑）
    3. `来源`：落子来源（玩家 `.source-human` / AI `.source-ai`）
    4. `落子`：着法名称（如 `炮二平五` / `h2e2`）
    5. `深度`：引擎搜索深度（depth）
    6. `节点`：搜索节点数（nodes）
    7. `NPS`：每秒搜索节点数（nodes per second）
    8. `耗时`：思考用时（毫秒/秒）
    9. `分数`：UCCI 评估分（正分 `.score-positive` 蓝字，负分 `.score-negative` 黄字，平分 `.score-neutral` 白字）
  * 表格交互：表头固定 (`sticky`)、滚动条跟随最新一手、隔行浅色高亮。
* **底部实时状态栏 (`#ai-current`)**：
  * 实时提示当前引擎思考状态（如：“象眼引擎正在深度搜索中... (已思考 1.8s, depth 12)”）。

### 2.4 对局总结浮层 (`#game-summary`)
* 对局结束（胜负、困毙、长将判负）时弹出的居中蒙版窗口。
* 包含提示文本 `#game-summary-text` 及【再来一局】按钮 `#restartbtn` 与【悔棋】按钮。

### 2.5 底部说明区块 (`#engine-note`)
* 底部说明段落，展示 ElephantEye (象眼) WASM 引擎特性、Web Worker 并行计算、5 秒思考上限说明及链接。
